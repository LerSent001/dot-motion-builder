# Platform Rendering QA

Validation date: September 20, 2026.

## Fixtures

- Continuous animation: a 6×6 hexagonal grid using Fish-eye Lens, Ghost Grid, and glow.
- Sequence animation: a two-frame star grid at 6 FPS using Breathe for inactive cells and glow.
- Both fixtures are generated by the current JavaScript and Swift exporters; no replacement renderer is used for the comparison.

## Web results

- Chromium loads the exported JavaScript Web Component in a local test host without network requests or runtime errors.
- A component displayed at 240 CSS px on a 3× device-pixel-ratio page renders to a 720×720 canvas.
- The continuous fixture has different pixel signatures at 0, 0.25, and 0.6 seconds.
- The sequence fixture keeps the same active frame at 0 and 0.09 seconds while inactive cells continue to animate. It advances to the next frame at 0.18 seconds, matching 6 FPS.
- Content remains inside the canvas at every sampled time; no output is blank or clipped.
- Browser regression tests cover `pause()`, `play()`, `seek()`, `speed`, resizing, and multiple instances.

## SwiftUI results

- Environment: Swift 6.3 and an iPhone 17 Pro / iOS 26.4 Simulator.
- Both exported Swift files compile directly into an arm64 iOS Simulator app without third-party dependencies.
- The app installs, cold-launches, displays a paused state, and plays both fixtures.
- Across screenshots taken 280 ms apart, 226,794 pixels change in the Fish-eye Lens fixture and 168,962 pixels change in the sequence fixture. The sequence also advances its active frame.
- In paused thresholded comparisons, foreground geometry overlap is 96.97% for the Fish-eye Lens fixture and 98.56% for the sequence fixture. Shape, spacing, scale, glow extent, and active-cell positions align.

## Conclusion

No supported editor setting or animation effect is missing from either export target.

The two renderers are not pixel-identical. Web Canvas and SwiftUI Canvas use different blur kernels, color compositing, and polygon antialiasing, which produces small differences around glow and diagonal edges. The measured differences are confined to edge treatment and do not change geometry, layout, color meaning, playback speed, sequence state, or inactive-cell animation.

## Reproduce the checks

1. Run `pnpm test` to generate and validate the export fixtures.
2. Run `node scripts/platform-web-qa.mjs` with Playwright available to perform browser pixel and timeline checks.
3. The browser hosts are `/tmp/dot-motion-custom-qa.html` and `/tmp/dot-motion-sequence-qa.html`.
4. The Swift fixtures are `/tmp/DotMotionCustomQA.swift` and `/tmp/DotMotionSequenceQA.swift`; add them to an iOS 15+ test host for native playback validation.
